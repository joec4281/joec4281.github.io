Sundry plugin for Take Command / TCC / TCC/LE

beta version 0.80.1     2026-10-09

Charles Dye

Purpose:

This plugin adds a hodgepodge of unrelated features to TCC. There is no connecting theme here; just odds and ends that don’t belong anywhere else.

Installation:

To use this plugin, copy Sundry.dll and Sundry.chm to some known location on your hard drive. (If you are still using the 32-bit version of Take Command, take Sundry-x86.dll instead of Sundry.dll.) Load the .DLL file with a PLUGIN /L command, for example:

plugin /l c:\bin\tcmd\test\sundry.dll

If you copy these files to a subdirectory named PlugIns within your Take Command program directory, the plugin will be loaded automatically when TCC starts.

Syntax Note:

The syntax definitions in the following text use these conventions for clarity:

BOLD CODEindicates text which must be typed exactly as shown.
CODEindicates optional text, which may be typed as shown or omitted.
Bold italicnames a required argument; a value must be supplied.
Regular italicnames an optional argument.
ellipsis…after an argument means that more than one may be given.

Examples are shown in a gray box:

rem   This is an example:
arraydump test


Some command options take an argument. These are shown with a colon between the option and its argument: /A:arg

If you like, you may substitute an equals sign for the colon: /A=arg This is handy if the arg is a filename, and you want to use tab completion to enter the filename.

Or you can omit the colon: /Aarg

New Commands:

ARRAYDUMP — Dump an array’s contents to stdout.

Syntax:
ARRAYDUMP /B:n /C:n0,n1,n2… /E:n /H /L /P /W:n arrayname

/B:nstarting line number
/C:n0,n1,n2…set column widths
/E:nending line number
/Hheader
/Lshow line numbers
/Ppage output
/W:nset line length
arraynameRequired. One- and two-dimensional arrays are supported.

ARRAYDUMP displays values in an array. It will not necessarily display all data. Rather, it tries to arrange output in neat columns, and truncates rows to fit your console window. Think of this as a quick way to see what’s in there, without having to write a loop — or a loop within a loop.


/C:n0,n1,n2… specifies your desired width for the first, second, third, etc. column. The maximum column width is 100 characters. If you prefix a - sign, values in that column will be left-justified; otherwise they are right-justified. If you type *, or if you do not supply a width, ARRAYDUMP make one up automatically.


/W:n specifies your desired line length. If you do not use /W:, the default is the console width if output is not redirected, or 100 if it is.


This command is not available in TCC/LE.


ECHOC — Expand escapes and display text.

Syntax:
ECHOC text

textstring to write to stdout

C-style character escapes will be expanded, and the resulting text written to stdout. No end-of-line will be appended. If you want an end-of-line, add \r\n to the end of the string.

Note that you must double any backslashes you want to display. If you want to show e.g. filenames with ECHOC, you can use @REPLACE to double any backslashes:

echoc Filename:  \e[4m %@replace[\,\\,%_cmdspec] \e[0m\r\n


HA — Highlight alternate lines of output text.

Syntax:
HA /B /CP:n /I /L /U /V

/Bbold (ANSI)
/CP:ninput code page
/Iitalics (ANSI)
/Lline numbers
/Uunderline (ANSI)
/Vreverse video (ANSI)

HA reads lines from a pipe, and writes them to standard output with alternate lines highlighted. Remember that pipe commands run in a new shell! To pipe to this command, you must ensure that this plugin is loaded in the new shell, e.g. by copying the plugin .DLL file to TCC’s PlugIns directory.

Using any of the ANSI modes (/B /I /U /V) overrides the default color-changing mode.

HA’s output is meant to go directly to the console. If you redirect HA’s output, you will probably get a text file full of ANSI gribble.

ping localhost | ha


HELPFOR — Locate and open a plugin’s help file.

Syntax:
HELPFOR /Q name

/Qquietly
namethe name of the plugin

HELPFOR searches directories in this order:

  • directory specified in a nameHELP environment variable (name is the plugin’s internal name)
  • directory specified in a PLUGINHELP environment variable
  • in the directory where the plugin .dll resides
  • in a Help directory within the plugin .dll’s directory
  • in the tcc.exe install directory
  • in a Help directory within tcc.exe’s directory
  • in C:\Windows\Help

Help files should have the same base name as the plugin’s internal name, and one of the following extensions:

  • .chm
  • .html or .htm
  • .txt
  • .doc or .docx
  • .pdf

If HELPFOR cannot find a help file in any of the above locations, and if the plugin’s PLUGININFO block includes a valid-looking web address, then the web page will be opened as a last resort.


MAZE — Generate a maze to stdout.

Syntax:
MAZE /L /M:n width height

/Llabyrinth mode
/M:ngenerate multiple mazes

Width and height are both optional.


QFIND — Find matching files quickly.

Syntax:
QFIND /A:attr /D /F /K /LC /M /N:flags /Q:n /T /T:acw /U /UTC /W /Z wildspec…

/A:attrfilter by attributes/A:-D
/Dshow time stamp
/Fshow fractional seconds; implies /D
/Ktrailing backslash for directory names
/LClocalize file times correctly
/Mno summary
/N:flagsdisable features
/Q:nquote displayed filenames/Q:0
/Tshow attributes
/T:acwwhich time stamp to use and display/T:W
/Ushow summary (default)
/UTCdisplay file times as UTC; implies /D
/Wshow day of the week; implies /D
/Zshow file sizes
wildspecsupports directory aliases and wildcards

QFIND is a simple, but quick, file finder. QFIND essentially does the same job as FFIND /A-D /S wildspec. For large and deeply-nested directory trees, QFIND should be faster than DIR or FFIND — and that is its only advantage.

With no arguments, QFIND lists all files in the current directory and below.

All searches are recursive; there is no /S. QFIND supports a limited subset of ranges.

QFIND does not support:

  • searching the contents of files
  • sorting
  • paging and prompting
  • flexible output formats
  • colored output

If no matching files are found, there is no error message. QFIND just doesn’t list any filenames.

•  Note: QFIND may not list files in the same order that DIR or FFIND would. This is by design, and not a bug.


/LC causes QFIND to localize file times correctly, taking Daylight Saving Time changes into account. This option affects both the /D time display, and any date or time ranges in effect. The default is to localize file times as TCC and cmd.exe do.


/N: disables features:

Ddo not search into hidden directories
Jdo not search into junctions
Zdo not search into system directories

The default behavior without /N: is to search into all subdirectories, regardless of their attributes. Note that this is different from how DIR /S and FFIND /S work without /A:.


/Q: controls quoting of filenames:

0do not quote filenames
1always quote filenames
2quote filenames as needed

/T:acw selects which time stamp to use and display:

Athe last-access time
Cthe creation time
Wthe last-write time

The default is W. The selected time stamp is used both to display (if /D is given), and for the date and time ranges (if /[D…] or /[T…] is given). Note that you cannot display one time stamp and filter by another; /T: controls both.


rem   Find all SAPI.DLL files in C:\Windows :
qfind c:\windows\sapi.dll

Wildcards:

QFIND supports some advanced wildcard features, but the syntax is different from TCC’s. Note that you must quote the filespec if you use any of these features!


A list of characters:

qfind "<ace>*"

… matches filenames beginning with an A, C, or E.

qfind "<v-z>*"

… matches filenames beginning with a V, W, X, Y, or Z.


A reversed list:

qfind "<!rst>*"

… matches filenames beginning with any character other than an R, S, or T.


Named character classes:

qfind "<[:upper:]>*"

… matches any filename beginning with an uppercase letter.

qfind "*<[:digit:]>.*"

… matches any filename containing a digit followed by a period.

qfind "c:\*<[:cntrl:]>*"

… matches any filename on drive C:\ containing a control character — very unlikely, but not impossible!


Alternations:

qfind "*.bat|*.cmd|*.btm"

… matches filenames ending in .bat, .cmd, or .btm.


Why the pain-in-the-ass less-than, greater-than, and pipe symbols? Because these characters are not legal in filenames, so the algorithm ‘knows’ that they are always wildcard characters and never intended to match actual characters in filenames. This simplifies (i.e. speeds) wildcard matching.

Ranges:

QFIND supports a limited subset of TCC’s ranges. Syntax is mostly similar to TCC.


Size range:/[Ssize1,size2]list only files within the range (inclusive)
 /[!Ssize1,size2]list only files not within the range

You can only give one size range. Size2 is optional, and may be +offset — added to size1.


Date range:/[Ddate1,date2]list only files in the given range (inclusive)
 /![Ddate1,date2]list only files not within the given range

You can only give one date range. The date range tests the time stamp selected with /T:acw. If you do not specify date1, it defaults to today’s date. Date2 defaults to the end of time. Either date may be given as -offset or +offset where offset is days before or after today (in date1) or date1 (in date2).

Note that date ranges do not support A C or W to select the date stamp.


Time range:/[Ttime1,time2]list only files in the given range (inclusive)
 /![Ttime1,time2]list only files not within the given range

You can only give one time range. The time range tests the time stamp selected with /T:acw. Time1 is required; time2 defaults to the current time. Either time may be given as -offset or +offset where offset is minutes before or after the current time (in time1) or time1 (in time2).

Note that time ranges do not support A C or W to select the time stamp.


Exclusion range:/[!wild1 wild2 wild3…]exclude files which match any of these

TCC’s syntax of ending an exclusion range with a backslash to prevent searching into matching subdirectories is not supported.

Owner ranges and description ranges are not supported.


TIME — Display or set the current system time.


This plugin adds a /C option to TCC’s internal TIME command. TIME’s operation is otherwise unchanged. See the regular Take Command help for information on using TIME.


TIME /C — Display time continuously.

Press any key to exit the time display.


New Functions:

@DIST — Returns the distance between two points.

Syntax:
%@DIST[x1,x2]
%@DIST[x1,y1,x2,y2]
%@DIST[x1,y1,z1,x2,y2,z2]

x1, x2X coordinates of the first and second points
y1, y2Y coordinates of the first and second points
z1, z2Z coordinates of the first and second points

@DIST calculates the distance between two points in one, two, or three dimensions. It therefore expects two, four, or six arguments.

rem   Calculate the distance between points (6,1) and (10,-2) :
echo %@dist[6,1,10,-2]


@EE — Expands TCC escape sequences in a string.

Syntax:
%@EE[string]

stringtext containing TCC escapes

TCC escape sequences such as ^e, ^q, and ^r will be expanded. Use @EE if you need to expand escapes in a string, e.g. before passing it to a function that doesn’t understand escapes.

@EE uses an internal TCC function to expand escapes, so only those escapes which your version of TCC recognizes will be expanded. For example, ^g will not be expanded in TCC/LE.


@FFIND — Returns the filename of the first matching file or subdirectory.

Syntax:
%@FFIND[/A:attribs /F /N:flags /S wildspec]

/A:attribsdefaults to everything (files and directories)
/Freturn full pathname
/N:flagsdisable:
   D - do not search into hidden directories
   J - do not search into junctions
   Z - do not search into system directories
/Ssearch into subdirectories; implies /F
wildspecwildcards and directory aliases are supported; defaults to *

This function only implements a tiny subset of the FFIND command’s features. It only returns the first matching file it finds. There is no provision for returning multiple filenames, or for searching for strings inside files. Ranges are not supported either.

If no matching file is found, @FFIND returns an empty string.

set zipfile=%@ffind[/s /a:-d *.zip]


@MEDIAN — Returns the median of a list of values.

Syntax:
%@MEDIAN[v0,v1,v2… vn]

v0, v1, etc.a list of values

You must provide at least one value. Separate values with commas or spaces. If any value contains a period, then all values will be treated as floating-point numbers. Otherwise, all will be treated as 64-bit integers.

echo %@median[1,2,3,5,7,100]


@TRI — Returns the nth triangular number.

Syntax:
%@TRI[n]

nrequired; must be < 6074001000

@TRI returns an unsigned 64-bit integer.

for /l %n in ( 0, 1, 20 ) echo %n - %@tri[%n]


New Variables:

_ASSETTAG — Returns the computer’s SMBIOS asset tag, if any.

Syntax:
%_ASSETTAG

_ASSETTAG looks for the SMBIOS chassis asset tag first. If it can’t find that, it tries for the baseboard asset tag next. If neither one is found, or if any error occurs, _ASSETTAG returns an empty string.

Most privately-owned computers will not have an asset tag set. This variable will be useful mainly in corporate or institutional environments.


_DAYSECOND — Returns the current time of day as seconds past midnight.

Syntax:
%_DAYSECOND

The return value ranges from 0 (midnight) through 86399 (11:59:59 P.M.)


New Hotkeys:

Ctrl-Q — Quotes the word at the cursor.

The word at the cursor will be wrapped in double quotes — unless it already has quotes and does not need them, in which case the quotes will be removed. Any double quotes within the word will be moved to the outside.

For example, if the cursor is on the string "c:\Program Files"\*.exe, pressing Ctrl-Q will change it to "c:\Program Files\*.exe".


Escape Sequences:

ECHOC supports these escape sequences:

Code:Expands to:Example:
\nnnoctal value, up to 777\101 → A
\\backslash (0x5c)
\aASCII BEL character (0x07)
\bbackspace
\ccomma
\eASCII ESC character (0x1b)
\fform feed (0x0c)
\kgrave accent (0x60)
\nline feed (0x0a)
\qdouble quotes (0x22)
\rcarriage return (0x0d)
\sspace (0x20)
\ttab (0x09)
\unnnnUnicode character, up to U+FFFF\u03a3 → Σ
\UnnnnnnnnUnicode character, up to U+10FFFF\U0001f63a → 😺
\vvertical tab (0x0b)
\xnnnnhexadecimal value, up to FFFF\x0041 → A
\#nnnnndecimal value, up to 65535\#65 → A

Note that case is significant for the letter after the backslash. All must be lowercase, except for \Uxxxxxxxx.

Case is not significant in hexadecimal values. \uxxxx and \xxxxx read up to four hexadecimal digits; \Uxxxxxxxx reads up to eight. You may use fewer than four (or eight) digits if the following character is not a valid hex digit.

Similarly, octal character escapes read up to three octal digits. You may use fewer than three if the following character is not an octal digit. Decimal escapes read up to five decimal digits; you may use fewer than five if the following character is not a digit.


Startup Message:

This plugin displays an informational line when it initializes. The message will be suppressed in transient or pipe shells. You can disable it for all shells by defining an environment variable named NOLOADMSG, for example:

set /e /u noloadmsg=1
