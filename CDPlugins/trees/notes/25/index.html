BangHistory plugin for Take Command / TCC / TCC/LE

beta version 0.61.0     2026-01-08

Charles Dye

Purpose:

This plugin adds a subset of Unix history features to TCC.

Installation:

To use this plugin, copy BangHistory.dll to some known location on your hard drive. (If you are still using the 32-bit version of Take Command, take BangHistory-x86.dll instead of BangHistory.dll.) Load the .DLL file with a PLUGIN /L command, for example:

plugin /l c:\bin\tcmd\test\banghistory.dll

If you copy the .DLL file to a subdirectory named PlugIns within your Take Command program directory, it will be loaded automatically when TCC starts.

Using It:

When you press Enter or Shift-Enter at the command line, BangHistory checks whether the command line begins with an exclamation point !. If so, the plugin attempts to retrieve a line from TCC’s command history. There are a few different ways you can specify the line to get.

Two exclamation points retrieves the most recent line from the command history, generally the last command you entered:

!!

A non-negative number recalls the nth line from the start of the command history. For example, to get the very earliest line in the command history:

!0

A negative number recalls the nth line from the end of the command history. To get the third-most-recent command:

!-3

!! is the same as !-1.

If the first character after the exclamation point is a letter, BangHistory will look for the most recent command beginning with that letter (or string, if there’s more than one). For instance, to get the most recent command beginning with a c:

!c

Note that the search is case-sensitive. If you type a capitol C, the plugin will look for a command beginning with an uppercase C. If you’re like me, it probably won’t find one.


Search and Replace: BangHistory can also do a simple search-and-replace when recalling a command line. The syntax is :s^old^new (instead of the caret, you can use any punctuation mark which does not appear in either string). Place it after the line specifier, with no spaces between:

!!:s^first^last

… would recall the most recent command, and replace the first instance of “first” with “last”. Note that this search is also case-sensitive, and only the first matching string will be replaced.


• Note:  BangHistory only works at the command line. It does nothing in batch files.

• Note:  The very first character on the command line must be an exclamation point. If it’s anything else, BangHistory does nothing. If for some ungodly reason you actually need to type a command beginning with an exclamation point, space before the command, or quote it.

• Note:  If you press Shift-Enter, BangHistory will recall the command and update the command line if possible, but it will not be executed until you hit Enter.

Configuration: The BANGH command

Syntax:
BANGH /A:n /B:n /D /I:n /Q /R /S /X:n /Z:n

/A:nallow whitespace between the ! and the number or search string1
/B:nbeep on errors1
/Drestore the plugin’s default settings
/I:ncase insensitive searches0
/Qquietly
/Rrestore any saved settings from the registry
/Ssave the current settings to the registry
/X:nexecute the command even if ! expansion failed1
/Z:nspecify how history entries are numbered0

Startup Message:

This plugin displays an informational line when it initializes. The message will be suppressed in transient or pipe shells. You can disable it for all shells by defining an environment variable named NOLOADMSG, for example:

set /e /u noloadmsg=1
